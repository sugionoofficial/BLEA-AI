Browser Companion

Hubungkan tab aplikasi, lalu biarkan BLEA Agent mengoperasikan tab tujuan.

Pilih tab tujuan dan izinkan domain tambahan sebelum agen menavigasi ke sana.

Mode otomatis hanya aktif jika baris pertama persis: lakukan tanpa konfirmasi. Selain itu, setiap langkah menunggu persetujuan.

Siap. Contoh: “cari … di Google”, “buka https://…”, “baca halaman”, “salin teks …”, “tempel ke kolom …”, “klik tombol …”, “isi kolom … dengan …”.

STOP menghentikan langkah berikutnya; klik yang sudah berjalan tidak bisa ditarik kembali. Pembayaran dan penghapusan diblokir. Task AI dimulai dari BLEA Agent → Browser live.
