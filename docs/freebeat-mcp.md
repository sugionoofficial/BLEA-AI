# Freebeat MCP: uji koneksi admin

`/admin/freebeat` hanya tersedia untuk admin dan hanya menawarkan OAuth serta `get_credit_balance`. Tidak ada endpoint generasi atau pembelian yang diaktifkan. Backend memeriksa role admin pada setiap permintaan, menggunakan pendaftaran OAuth dinamis, PKCE S256, `freebeat:read`, dan state yang terikat ke browser. Endpoint resmi: `https://freebeat.ai/api/mcp`.

Worker memerlukan `PROVIDER_CREDENTIAL_ENCRYPTION_KEY` yang sudah digunakan fitur Gmail. Jangan ganti kunci yang ada. Callback default: `https://blea-ai.blea-ai.workers.dev/api/freebeat/callback`. Opsional `FREEBEAT_OAUTH_REDIRECT_URI` dapat mengatur domain HTTPS lain dengan path yang sama; buka aplikasi dari origin tersebut agar cookie OAuth tersedia pada callback.

Token akses untuk pengujian dienkripsi AES-GCM ke cookie HttpOnly, Secure, SameSite=Lax, terikat ID admin, dan digunakan hanya setelah verifikasi admin. Tidak ada token refresh yang disimpan. Sesi berlaku paling lama satu jam (atau masa token yang lebih pendek); hubungkan ulang setelah kedaluwarsa. Setiap admin/browser punya sesi sendiri, belum ada akun provider bersama untuk pengguna. Tombol Putuskan menghapus cookie dan mencoba mencabut token; jika gagal, cabut akses di Freebeat. Perubahan kunci enkripsi juga mengakhiri sesi ini dan akan memengaruhi fitur Gmail yang memakai kunci yang sama.

Koneksi, saldo, cakupan OAuth, dan ketersediaan pada akun/plan belum diuji pada Freebeat live. Tidak ada bypass pembatasan plan atau kredit. Penggunaan kredit Freebeat gratis bersifat nonkomersial menurut ketentuan Freebeat; akses untuk pengguna BLEA dan penggunaan komersial memerlukan pengecekan izin terpisah. Sistem kredit BLEA tidak terhubung ke Freebeat, dan pembelian tetap nonaktif.

Pendaftaran dinamis meminta scope `freebeat:read`, response type `code`, dan grant `authorization_code` serta `refresh_token`. Kombinasi metadata ini diterima dalam satu uji registrasi langsung dengan callback default; login, pertukaran token, scope, dan MCP masih perlu diuji secara live. Grant refresh hanya metadata registrasi: BLEA tidak menyimpan atau menggunakan refresh token. Klien uji yang dibuat di luar BLEA tidak dipakai ulang; setiap percobaan koneksi BLEA membuat registrasi baru.

Unit/integration tests: `node --test tests/freebeat-mcp.test.js`; pengujian menggunakan respons upstream tiruan, bukan akun Freebeat asli.

## Diagnosis koneksi

Pada tahap registrasi atau pertukaran token, pesan menyertakan kode tetap yang aman untuk dibagikan: `FB-REGISTER-NETWORK`/`FB-TOKEN-NETWORK` berarti permintaan gagal sebelum menerima respons; `TIMEOUT` berarti batas waktu terlampaui; `HTTP` berarti Freebeat memberi respons penolakan; `RESPONSE` berarti respons JSON tidak valid; `REDIRECT` berarti pengalihan ditolak demi keamanan. Status HTTP registrasi dicantumkan jika tersedia. Detail mentah kesalahan, kode OAuth dan token tidak ditampilkan atau dicatat. Pengalihan 307/308 hanya diikuti sekali ke endpoint yang sama pada origin Freebeat yang sama, termasuk variasi garis miring akhir; semua pengalihan lain ditolak.

Jika registrasi mengembalikan HTTP 400 dengan kode kesalahan OAuth standar, halaman menampilkan kode yang termasuk daftar aman seperti `invalid_redirect_uri` atau `invalid_client_metadata`. Jika penyedia menyebut loopback pada penolakan redirect, halaman menampilkan petunjuk tetap tanpa menyalin deskripsi mentah. Isi respons penyedia, token, kode otorisasi, dan detail lain tidak ditampilkan atau dicatat. Respons kesalahan dibatasi 16 KiB.

## Eksperimen saldo situs memakai cookie (terpisah dari MCP)

Bagian admin **Uji saldo situs dengan cookie** adalah diagnostik sekali pakai, bukan OAuth, MCP, integrasi akun bersama, atau sistem generasi. Gunakan hanya akun sendiri dan hanya jika ketentuan serta plan Freebeat mengizinkan akses ini. Freebeat mendokumentasikan OAuth untuk MCP, bukan penggunaan endpoint situs ini sebagai API publik. Hasil dan kompatibilitasnya tidak dijamin; kredit gratis tidak otomatis boleh dipakai secara komersial. Plan dengan manfaat manual-only dapat melarang akses otomatis/pihak ketiga.

Cookie sesi dapat memberikan akses luas ke akun Freebeat. Hanya setelah memahami risikonya, admin dapat menyalin **nilai header `Cookie` saja** dari permintaan `GET https://freebeat.ai/api/proxy/v1/user/credits/findCredits` di tab Network browser yang sudah login, lalu memasukkannya ke kolom bertipe password di halaman admin BLEA yang tepercaya. Jangan salin header lain atau `Copy as cURL`, dan jangan pernah kirim cookie ke chat, tiket atau pihak lain. Beberapa browser mungkin tidak menampilkan nilai header ini. Jangan menonaktifkan perlindungan browser untuk mendapatkannya.

Saat dikirim, cookie melewati browser, jaringan dan infrastruktur BLEA/Cloudflare, lalu diteruskan hanya dalam header `Cookie` ke endpoint HTTPS saldo tersebut. Admin harus mempercayai operator dan infrastruktur tersebut. Endpoint server memerlukan login bearer admin dan Origin BLEA yang sama, membatasi panjang input/respons, menolak pengalihan, dan tidak menampilkan isi respons mentah atau kesalahan dari penyedia. Hanya jumlah saldo numerik terpilih yang dikembalikan. Fitur ini tidak menyimpan cookie dalam database, localStorage, atau cookie BLEA, dan tidak sengaja mencatatnya; kolom dikosongkan saat submit. Cookie tetap dapat berada sementara di memori browser/Worker atau pada clipboard/peralatan browser, dan log/ekstensi/infrastruktur pihak ketiga di luar fitur perlu dipertimbangkan. Bersihkan clipboard setelah digunakan. Jika cookie bocor, akhiri sesi melalui Freebeat dan periksa keamanan akun.

Sesi mungkin kedaluwarsa atau memerlukan header tambahan; status HTTP 200 tidak cukup tanpa respons saldo yang valid. Permintaan ke MCP yang menggunakan cookie browser pada uji awal mengembalikan 401. Jika tes gagal, jangan mencoba melewati pembatasan penyedia; gunakan OAuth resmi atau tanyakan dukungan Freebeat. Uji tiruan: `node --test tests/freebeat-site-balance.test.js`. Belum ada jaminan pengujian live dari Worker berhasil.
