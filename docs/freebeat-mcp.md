# Freebeat MCP: uji koneksi admin

`/admin/freebeat` hanya tersedia untuk admin dan menawarkan OAuth, saldo, daftar model, inspeksi struktur tool, diagnostik quote dan uji generasi gambar admin dengan persetujuan untuk setiap pengiriman. Pembelian BLEA dan generasi untuk pengguna lain tidak diaktifkan. Backend memeriksa role admin pada setiap permintaan, menggunakan pendaftaran OAuth dinamis, PKCE S256 dan state yang terikat ke browser. Tombol Hubungkan Freebeat meminta `freebeat:read freebeat:generate` sekaligus; izin yang benar-benar diberikan tetap ditentukan Freebeat dan persetujuan admin. Endpoint resmi: `https://freebeat.ai/api/mcp`.

Worker memerlukan `PROVIDER_CREDENTIAL_ENCRYPTION_KEY` yang sudah digunakan fitur Gmail. Jangan ganti kunci yang ada. Callback default: `https://blea-ai.blea-ai.workers.dev/api/freebeat/callback`. Opsional `FREEBEAT_OAUTH_REDIRECT_URI` dapat mengatur domain HTTPS lain dengan path yang sama; buka aplikasi dari origin tersebut agar cookie OAuth tersedia pada callback.

Token akses untuk pengujian dienkripsi AES-GCM ke cookie HttpOnly, Secure, SameSite=Lax, terikat ID admin, dan digunakan hanya setelah verifikasi admin. Tidak ada token refresh yang disimpan. Sesi berlaku paling lama satu jam (atau masa token yang lebih pendek); hubungkan ulang setelah kedaluwarsa. Setiap admin/browser punya sesi sendiri, belum ada akun provider bersama untuk pengguna. Tombol Putuskan menghapus cookie dan mencoba mencabut token; jika gagal, cabut akses di Freebeat. Perubahan kunci enkripsi juga mengakhiri sesi ini dan akan memengaruhi fitur Gmail yang memakai kunci yang sama.

Login OAuth, saldo MCP, daftar model dan quote gambar telah diuji live oleh admin. Pengiriman gambar dan format hasil belum diuji live. Tidak ada bypass pembatasan plan atau kredit. Penggunaan kredit Freebeat gratis bersifat nonkomersial menurut ketentuan Freebeat; akses untuk pengguna BLEA dan penggunaan komersial memerlukan pengecekan izin terpisah. Sistem kredit BLEA tidak terhubung ke Freebeat, dan pembelian tetap nonaktif.

Pendaftaran dinamis meminta response type `code`, grant `authorization_code` serta `refresh_token`, dan kedua scope baca dan generasi. Pendaftaran `freebeat:read` dengan callback default, login, dan pembacaan saldo MCP berhasil diuji live; setelah flow gambar, admin melihat tool `generate_image` dan memperoleh respons quote, tetapi pemanggilan generasi belum diuji live. Status izin gambar memperhitungkan scope pada respons token; jika respons menghilangkan `scope`, RFC 6749 menganggapnya sama dengan scope yang diminta, tetapi penggunaan aktual tetap belum terverifikasi. Sesi lama tanpa metadata scope diperlakukan sebagai baca saja. Jika Freebeat hanya memberikan scope baca, sesi tetap bisa membaca saldo dan menampilkan pemberitahuan izin terbatas. Grant refresh hanya metadata registrasi: BLEA tidak menyimpan atau menggunakan refresh token. Setiap percobaan koneksi BLEA membuat registrasi baru.

Unit/integration tests: `node --test tests/freebeat-mcp.test.js`; pengujian menggunakan respons upstream tiruan, bukan akun Freebeat asli. Eksperimen saldo situs melalui input cookie dan endpoint `site-balance` telah dihapus; tombol **Periksa saldo** resmi melalui MCP OAuth tetap tersedia.

## Diagnosis koneksi

Pada tahap registrasi atau pertukaran token, pesan menyertakan kode tetap yang aman untuk dibagikan: `FB-REGISTER-NETWORK`/`FB-TOKEN-NETWORK` berarti permintaan gagal sebelum menerima respons; `TIMEOUT` berarti batas waktu terlampaui; `HTTP` berarti Freebeat memberi respons penolakan; `RESPONSE` berarti respons JSON tidak valid; `REDIRECT` berarti pengalihan ditolak demi keamanan. Status HTTP registrasi dicantumkan jika tersedia. Detail mentah kesalahan, kode OAuth dan token tidak ditampilkan atau dicatat. Pengalihan 307/308 hanya diikuti sekali ke endpoint yang sama pada origin Freebeat yang sama, termasuk variasi garis miring akhir; semua pengalihan lain ditolak.

Jika registrasi mengembalikan HTTP 400 dengan kode kesalahan OAuth standar, halaman menampilkan kode yang termasuk daftar aman seperti `invalid_redirect_uri` atau `invalid_client_metadata`. Jika penyedia menyebut loopback pada penolakan redirect, halaman menampilkan petunjuk tetap tanpa menyalin deskripsi mentah. Isi respons penyedia, token, kode otorisasi, dan detail lain tidak ditampilkan atau dicatat. Respons kesalahan dibatasi 16 KiB.

Untuk pemeriksaan saldo, kode `FB-MCP-INIT-*`, `FB-MCP-NOTIFY-*`, atau `FB-MCP-BALANCE-*` menunjukkan tahap yang gagal. Tahap `INSPECT` dan `MODELS` untuk persiapan gambar. Akhir kode `NETWORK`, `TIMEOUT`, `REDIRECT`, `HTTP`, `RPC`, `RESPONSE`, atau `SIZE` menunjukkan kategori aman; status HTTP disertakan jika relevan. Hanya tahap, kategori, dan status HTTP dicatat, bukan rincian provider atau kredensial. Pengalihan MCP selalu ditolak dan token tidak diteruskan ke tujuan lain. Respons saldo dibatasi 64 KiB dan respons discovery 256 KiB selama pembacaan; untuk SSE pembacaan berakhir saat respons dengan ID yang diharapkan diterima, tanpa menunggu stream ditutup.

## Persiapan gambar tanpa biaya

Tombol **Lihat model gambar** memanggil hanya `list_models` dengan `type=image`; tombol **Periksa skema tool gambar** memanggil `tools/list` (maksimal lima halaman) dan hanya menampilkan struktur terbatas untuk lima tool terkait gambar. Nilai contoh, deskripsi, URL, dan tool lain tidak diteruskan. Model dibatasi hingga 100 nama dan ID. Jika format model atau skema provider tidak cocok, tampilkan error aman, jangan menebak. Kedua langkah tetap admin-only, memakai sesi OAuth read-only yang sudah ada dan tidak memanggil `generate_image` atau `quote_generation`.

Form **Periksa respons quote** adalah diagnostik baca-saja. Hanya menerima ID model bilangan bulat dan prompt 1–2000 karakter, lalu memanggil `quote_generation` dengan `tool=generate_image` dan `parameters={model_id,prompt}`. Prompt dikirim ke Freebeat; jangan masukkan data rahasia. Respons disaring menjadi struktur dan nilai numerik/boolean serta daftar kecil nilai teks aman; teks lain, prompt dan identifier privat tidak diteruskan. Untuk field `status`, kosakata aman diperluas (misalnya `ok`, `quoted`, `priced`); nilai yang tidak ada dalam daftar tetap tersembunyi. Ini hanya diagnostik, bukan pernyataan bahwa semua nilai tersebut dipakai atau memiliki arti tertentu di Freebeat. Output ini belum diinterpretasikan sebagai biaya atau dijadikan persetujuan: bentuk respons nyata dan arti angkanya belum diverifikasi. Tidak ada `max_credits` atau `accept_unknown_cost` yang dikirim pada langkah ini.

Pada pengujian live dengan prompt yang sama, model 80 mengembalikan `credits: 23` tetapi status, sumber dan pesan terfilter, sedangkan model 108 mengembalikan status `unavailable`. Ini tidak cukup untuk memverifikasi 23 sebagai quote final ataupun menyimpulkan penyebab `unavailable`. Uji ulang model 80 dengan filter status yang baru setelah deployment; jika tetap tersembunyi, status belum diketahui dan jangan menyetujui biaya berdasarkan angka saja.

Jika penyimpanan tidak tersedia atau belum dimigrasi, pengiriman gagal tertutup sebelum pemanggilan generasi. Jangan membagikan kunci service role. Migration perlu diterapkan sekali pada project yang benar sebelum deployment; jangan membuat atau mengubah tabel billing BLEA.\n\nMasukkan model dan prompt pada bagian **Uji generasi gambar admin**, lalu **Siapkan quote untuk persetujuan**. Jika tombol nonaktif, petunjuk di bawah tombol menjelaskan apakah koneksi sedang diperiksa, sesi atau izin gambar belum tersedia, kolom belum lengkap, atau permintaan masih berjalan. Sesi sementara tidak mempertahankan input setelah halaman dimuat ulang; jika perlu, hubungkan ulang dengan **Hubungkan Freebeat** dan setujui izin generasi, lalu isi kembali model dan prompt. Memeriksa atau menyiapkan quote tidak menjalankan generasi. Server memeriksa model di katalog live, memanggil `get_model_help` dan `quote_generation` untuk model dan prompt persis tersebut; uji ini hanya mengirim parameter wajib, memakai default Freebeat dan tidak menebak opsi. Hanya respons `status=quoted` dengan `credits` numerik nonnegatif yang diterima untuk persiapan. Respons ini pernah terlihat untuk model 80, tetapi kontrak semantik dan biaya akhir masih perlu diverifikasi; teks sumber dan pesan penyedia tetap disembunyikan. Tidak ada opsi biaya tak diketahui.\n\nPersetujuan berisi prompt dan ID model yang ditampilkan serta batas `max_credits` tepat sebesar quote yang ditampilkan. Admin harus mencentang konfirmasi dan menekan tombol pengiriman satu kali. Bukti persetujuan terenkripsi sementara selama lima menit, terikat pada admin, token OAuth dan input; tidak disimpan di localStorage. Server meminta quote lagi dan menolak pengiriman bila angka atau status berubah. Token tidak dapat diubah untuk mengganti prompt, model atau batas. Ini mengirim `max_credits` tetapi tidak mengirim `accept_unknown_cost`; tidak menaikkan batas otomatis. Freebeat tetap menentukan biaya aktual, dan quote bukan tagihan maupun jaminan refund.\n\nSebelum panggilan yang mungkin berbayar, Worker memasukkan ID persetujuan unik ke tabel service-role-only. Indeks database melarang pengulangan receipt dan lebih dari satu pengiriman belum terselesaikan per admin. Timeout, respons tidak dikenal, atau kegagalan penyimpanan pascapengiriman dianggap **hasil tidak pasti**, mungkin sudah ditagih, dan tidak pernah dicoba ulang secara otomatis. Baris `dispatching` atau `unknown` mengunci pengiriman baru tanpa kedaluwarsa otomatis. Jika respons insert database sendiri hilang, Worker tidak memanggil Freebeat dan baris mungkin tetap terkunci. Jangan hapus baris karena ID yang sama dapat dipakai ulang.\n\nOperator harus merekonsiliasi hasil dengan aktivitas dan/atau dukungan Freebeat sebelum intervensi. Setelah yakin statusnya, operator dengan akses database yang berwenang dapat menandai baris `dispatching` atau `unknown` sebagai `reviewed`, membiarkan `task_id` null, untuk membuka kunci; ini tidak berarti refund dan tidak memicu ulang permintaan. Jika tugas ditemukan dan ID-nya tervalidasi, operator dapat menyimpan ID dan menetapkan `submitted`; jangan pernah menebak atau memindahkan tugas antar admin. Tidak tersedia tombol reset dari browser. Catatan hanya memuat admin, model, quote/batas, status, waktu, hash token sesi dan ID tugas, bukan prompt atau token.\n\n**Periksa catatan uji** menampilkan maksimum 20 catatan milik admin. Untuk `submitted`, **Periksa status** memanggil `get_task_status` menggunakan ID tugas yang disimpan, bukan ID arbitrer dari browser. Polling hanya tersedia selama sesi OAuth yang sama; setelah token kedaluwarsa atau berganti, periksa tugas di Freebeat secara manual. Link gambar HTTPS dari penyedia ditampilkan sebagai tombol **Buka hasil gambar** yang membuka tab baru, bukan di-fetch server atau dimuat diam-diam; membukanya menghubungkan browser ke host penyedia. Jika status selesai tetapi tidak ada URL yang bisa ditampilkan, periksa kembali status atau lihat akun Freebeat, jangan buat generasi ulang. Nilai tagihan/refund yang tidak dilaporkan tetap null. Jangan bagikan ID tugas, URL bertanda tangan, prompt pribadi, token atau cookie.\n\nGenerasi ini dan bentuk `batch_id`/hasil status belum terverifikasi live; jika respons tidak cocok, anggap tidak pasti dan jangan ulangi. Uji ini tidak membangun akun provider bersama, riwayat gambar end-user atau sistem pengeluaran BLEA; pembelian BLEA tetap dinonaktifkan.

## Persiapan uji video tanpa biaya

Saat sesi terhubung, daftar dropdown dimuat dari `list_models(type=video)`; tombol **Muat ulang model video** memperbarui daftar. Hanya ID bilangan bulat yang dapat digunakan endpoint diagnostik dan ditampilkan; duplikat dan ID lain disaring. Daftar dibatasi 100 item dan dapat tidak lengkap; muncul di daftar bukan jaminan akses, dukungan opsi atau harga. Jika daftar gagal dimuat, kesalahan ditampilkan dan dapat dicoba lagi. **Periksa skema tool video** tetap menampilkan skema yang disaring. Keduanya tidak membuat video atau memakai kredit.

Pilih satu model di dropdown, isi satu prompt dan URL HTTPS gambar, lalu gunakan **Periksa informasi model** dan **Periksa quote**. Kedua tombol masing-masing memanggil `get_model_help` dan `quote_generation` untuk model terpilih. Quote menggunakan mode gambar, 5 detik dan 480p; opsi lain memakai default Freebeat. Respons disaring dan mungkin tidak lengkap atau unavailable. Prompt dan URL dikirim ke Freebeat, tetapi tidak disertakan dalam hasil salin. Mengubah model, prompt, URL atau daftar model menghapus quote lama. Quote bukan biaya akhir atau persetujuan generasi.

Admin dapat membuka **Upload gambar ke Supabase (opsional)** untuk mengunggah JPG/PNG/WebP maksimal 10 MB setelah menyetujui peringatan. Bucket `ai-studio-uploads` bersifat publik; gambar dan URL dapat ditemukan atau dibuka tanpa login. Jangan unggah data pribadi. File tidak kedaluwarsa otomatis; tombol hapus hanya tersedia selama halaman terbuka, kemudian hapus melalui dashboard Storage. Penghapusan tidak menghapus salinan atau cache pihak lain. Pengguna terautentikasi lainnya juga dapat mengunggah ke bucket bersama sesuai kebijakan yang ada.

Uji berbayar admin tersedia untuk model numerik yang dipilih dari katalog video terkini dan memiliki quote valid. Pilihan model diikat ke persetujuan satu kali; dukungan 5 detik/480p dan harga akhir tetap ditentukan Freebeat dan belum dijamin.

## Uji video berbayar khusus admin

Fitur memerlukan migrasi `20261118000005_create_freebeat_admin_video_tests.sql` dan service-role Worker. Pada project BLEA-AI `lwknqvgnxgecptkvtkfb`, migrasi ini sudah diterapkan sebagai versi `20261118152213`; jangan menerapkannya lagi hanya karena versi berbeda dari nama berkas. Tanpa tabel atau izin, pengiriman gagal sebelum pemanggilan berbayar. Uji hanya untuk akun OAuth admin, bukan pengguna lain atau kredit BLEA. Freebeat menandai model member-only; dukungan 5 detik/480p dan perilaku aktual generasi belum dikonfirmasi. Periksa ketentuan penggunaan dan plan; manfaat yang hanya untuk web tidak otomatis berlaku untuk MCP.

**Siapkan quote untuk persetujuan video** memeriksa model terpilih di katalog live, memanggil help dan meminta quote baru untuk model tersebut, tipe image, satu URL, prompt, 5 detik dan 480p. Pilihan model 186 pernah menghasilkan quote 135, tetapi quote tersebut tidak menjamin quote atau biaya berikutnya. Admin memeriksa nilai tersebut dan batas, lalu secara eksplisit mencentang dan menekan tombol untuk satu video. Hanya `status=quoted` dengan kredit numerik terbatas diperbolehkan. Server mengikat receipt terenkripsi pada admin, sesi, parameter persis dan quote selama lima menit, meminta quote ulang dan menolak apabila nilai berubah; tidak pernah mengirim `accept_unknown_cost`. `max_credits` dikirim sebesar quote, bukan jaminan biaya aktual atau refund. Gambar pada URL bisa berubah di luar kendali BLEA dan Freebeat menerima prompt serta URL.

Sebelum mengirim `generate_video`, Worker membuat catatan service-role-only dengan ID unik. Catatan `dispatching` atau `unknown` mengunci pengiriman video berikutnya untuk admin tersebut tanpa kedaluwarsa otomatis. Respons hilang, timeout, format tak dikenal, atau kegagalan penyimpanan setelah pengiriman dianggap tidak pasti dan tidak dicoba ulang. Insert database yang responsnya hilang juga mengunci meski Freebeat belum dipanggil. Jangan ulangi sebelum memeriksa catatan dan aktivitas akun Freebeat. Hanya operator berwenang setelah rekonsiliasi dapat menandai catatan `dispatching`/`unknown` sebagai `reviewed` untuk membuka kunci; jangan hapus baris karena receipt yang sama bisa digunakan lagi. Jika task ID ditemukan secara pasti, operator dapat menetapkan `submitted` dengan ID tervalidasi. Lock video terpisah dari lock uji gambar; keduanya bukan ledger kredit BLEA.

Untuk catatan `submitted`, tombol status memakai `get_task_status` dengan batch ID yang disimpan dan hanya pada sesi Freebeat yang sama. Untuk status gagal atau membutuhkan tindakan, hasil yang bisa disalin memuat status, billing dan field `failure.stage`, `failure.reason`, `failure.retryable` yang disaring pada tingkat batch dan item. Hanya kode yang cocok tepat dengan daftar aman ditampilkan; teks lain disembunyikan, dan nilai hilang tetap null. Hasil ini dapat tetap tidak menjelaskan penyebab; informasi `retryable` bukan persetujuan baru untuk generasi. Bila rincian tetap tersembunyi, admin dapat mencentang peringatan dan memilih **Tampilkan pesan kegagalan pribadi** pada tugas yang sama. Worker memanggil `get_task_status` lagi, hanya dengan akun dan sesi pengiriman yang sama; tidak memanggil generasi. Field `failure.reason`, `error_code`, `error_message` dan `message` pada batch dan item (maksimal 10 item, 2000 karakter per pesan) yang masih dikembalikan `get_task_status` ditampilkan di layar setelah penyamaran pola URL, email dan kredensial yang dikenal; respons awal pengiriman tidak disimpan sehingga pesan yang hanya ada di respons itu tidak dapat dipulihkan; pesan tidak disimpan, dicatat, atau dimasukkan ke blok salin. Penyaringan ini tidak menjamin semua data sensitif terhapus, dan teks mungkin mengandung prompt atau rahasia. Jangan bagikan teks mentah; jelaskan hanya penyebabnya dengan kata sendiri. Tombol sembunyikan menghapus pesan dari tampilan; pesan juga hilang saat sesi putus atau halaman ditutup. Jangan tampilkan token, URL atau prompt pribadi kepada pihak lain. Link HTTPS video yang disaring dibuka secara eksplisit di tab baru; jangan bagikan URL pribadi. Tagihan/refund yang tidak dilaporkan tetap tidak diketahui. Jika hasil tidak tersedia, jangan ulangi generasi. Pada uji live pertama user melaporkan status gagal dan `charged: 0`; penyebab dan refund/biaya bersih belum diketahui. Penggunaan komersial atau untuk pengguna lain memerlukan izin provider, dan pembelian BLEA tetap nonaktif.
