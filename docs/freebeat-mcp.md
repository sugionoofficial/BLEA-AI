# Freebeat MCP: uji koneksi admin

`/admin/freebeat` hanya tersedia untuk admin dan menawarkan OAuth, saldo, daftar model, inspeksi struktur tool, diagnostik quote dan uji generasi gambar admin dengan persetujuan untuk setiap pengiriman. Pembelian BLEA dan generasi untuk pengguna lain tidak diaktifkan. Backend memeriksa role admin pada setiap permintaan, menggunakan pendaftaran OAuth dinamis, PKCE S256 dan state yang terikat ke browser. Login biasa meminta `freebeat:read`; tombol terpisah secara eksplisit meminta `freebeat:read freebeat:generate`. Endpoint resmi: `https://freebeat.ai/api/mcp`.

Worker memerlukan `PROVIDER_CREDENTIAL_ENCRYPTION_KEY` yang sudah digunakan fitur Gmail. Jangan ganti kunci yang ada. Callback default: `https://blea-ai.blea-ai.workers.dev/api/freebeat/callback`. Opsional `FREEBEAT_OAUTH_REDIRECT_URI` dapat mengatur domain HTTPS lain dengan path yang sama; buka aplikasi dari origin tersebut agar cookie OAuth tersedia pada callback.

Token akses untuk pengujian dienkripsi AES-GCM ke cookie HttpOnly, Secure, SameSite=Lax, terikat ID admin, dan digunakan hanya setelah verifikasi admin. Tidak ada token refresh yang disimpan. Sesi berlaku paling lama satu jam (atau masa token yang lebih pendek); hubungkan ulang setelah kedaluwarsa. Setiap admin/browser punya sesi sendiri, belum ada akun provider bersama untuk pengguna. Tombol Putuskan menghapus cookie dan mencoba mencabut token; jika gagal, cabut akses di Freebeat. Perubahan kunci enkripsi juga mengakhiri sesi ini dan akan memengaruhi fitur Gmail yang memakai kunci yang sama.

Login OAuth, saldo MCP, daftar model dan quote gambar telah diuji live oleh admin. Pengiriman gambar dan format hasil belum diuji live. Tidak ada bypass pembatasan plan atau kredit. Penggunaan kredit Freebeat gratis bersifat nonkomersial menurut ketentuan Freebeat; akses untuk pengguna BLEA dan penggunaan komersial memerlukan pengecekan izin terpisah. Sistem kredit BLEA tidak terhubung ke Freebeat, dan pembelian tetap nonaktif.

Pendaftaran dinamis meminta response type `code`, grant `authorization_code` serta `refresh_token`, dan scope yang diminta sesuai tombol. Pendaftaran `freebeat:read` dengan callback default, login, dan pembacaan saldo MCP berhasil diuji live; setelah flow gambar, admin melihat tool `generate_image` dan memperoleh respons quote, tetapi pemanggilan generasi belum diuji live. Status izin gambar memperhitungkan scope pada respons token; jika respons menghilangkan `scope`, RFC 6749 menganggapnya sama dengan scope yang diminta, tetapi penggunaan aktual tetap belum terverifikasi. Sesi lama tanpa metadata scope diperlakukan sebagai baca saja. Jika Freebeat hanya memberikan scope baca, sesi tetap bisa membaca saldo dan menampilkan pemberitahuan izin terbatas. Grant refresh hanya metadata registrasi: BLEA tidak menyimpan atau menggunakan refresh token. Setiap percobaan koneksi BLEA membuat registrasi baru.

Unit/integration tests: `node --test tests/freebeat-mcp.test.js`; pengujian menggunakan respons upstream tiruan, bukan akun Freebeat asli.

## Diagnosis koneksi

Pada tahap registrasi atau pertukaran token, pesan menyertakan kode tetap yang aman untuk dibagikan: `FB-REGISTER-NETWORK`/`FB-TOKEN-NETWORK` berarti permintaan gagal sebelum menerima respons; `TIMEOUT` berarti batas waktu terlampaui; `HTTP` berarti Freebeat memberi respons penolakan; `RESPONSE` berarti respons JSON tidak valid; `REDIRECT` berarti pengalihan ditolak demi keamanan. Status HTTP registrasi dicantumkan jika tersedia. Detail mentah kesalahan, kode OAuth dan token tidak ditampilkan atau dicatat. Pengalihan 307/308 hanya diikuti sekali ke endpoint yang sama pada origin Freebeat yang sama, termasuk variasi garis miring akhir; semua pengalihan lain ditolak.

Jika registrasi mengembalikan HTTP 400 dengan kode kesalahan OAuth standar, halaman menampilkan kode yang termasuk daftar aman seperti `invalid_redirect_uri` atau `invalid_client_metadata`. Jika penyedia menyebut loopback pada penolakan redirect, halaman menampilkan petunjuk tetap tanpa menyalin deskripsi mentah. Isi respons penyedia, token, kode otorisasi, dan detail lain tidak ditampilkan atau dicatat. Respons kesalahan dibatasi 16 KiB.

Untuk pemeriksaan saldo, kode `FB-MCP-INIT-*`, `FB-MCP-NOTIFY-*`, atau `FB-MCP-BALANCE-*` menunjukkan tahap yang gagal. Tahap `INSPECT` dan `MODELS` untuk persiapan gambar. Akhir kode `NETWORK`, `TIMEOUT`, `REDIRECT`, `HTTP`, `RPC`, `RESPONSE`, atau `SIZE` menunjukkan kategori aman; status HTTP disertakan jika relevan. Hanya tahap, kategori, dan status HTTP dicatat, bukan rincian provider atau kredensial. Pengalihan MCP selalu ditolak dan token tidak diteruskan ke tujuan lain. Respons saldo dibatasi 64 KiB dan respons discovery 256 KiB selama pembacaan; untuk SSE pembacaan berakhir saat respons dengan ID yang diharapkan diterima, tanpa menunggu stream ditutup.

## Persiapan gambar tanpa biaya

Tombol **Lihat model gambar** memanggil hanya `list_models` dengan `type=image`; tombol **Periksa skema tool gambar** memanggil `tools/list` (maksimal lima halaman) dan hanya menampilkan struktur terbatas untuk lima tool terkait gambar. Nilai contoh, deskripsi, URL, dan tool lain tidak diteruskan. Model dibatasi hingga 100 nama dan ID. Jika format model atau skema provider tidak cocok, tampilkan error aman, jangan menebak. Kedua langkah tetap admin-only, memakai sesi OAuth read-only yang sudah ada dan tidak memanggil `generate_image` atau `quote_generation`.

Form **Periksa respons quote** adalah diagnostik baca-saja. Hanya menerima ID model bilangan bulat dan prompt 1–2000 karakter, lalu memanggil `quote_generation` dengan `tool=generate_image` dan `parameters={model_id,prompt}`. Prompt dikirim ke Freebeat; jangan masukkan data rahasia. Respons disaring menjadi struktur dan nilai numerik/boolean serta daftar kecil nilai teks aman; teks lain, prompt dan identifier privat tidak diteruskan. Untuk field `status`, kosakata aman diperluas (misalnya `ok`, `quoted`, `priced`); nilai yang tidak ada dalam daftar tetap tersembunyi. Ini hanya diagnostik, bukan pernyataan bahwa semua nilai tersebut dipakai atau memiliki arti tertentu di Freebeat. Output ini belum diinterpretasikan sebagai biaya atau dijadikan persetujuan: bentuk respons nyata dan arti angkanya belum diverifikasi. Tidak ada `max_credits` atau `accept_unknown_cost` yang dikirim pada langkah ini.

Pada pengujian live dengan prompt yang sama, model 80 mengembalikan `credits: 23` tetapi status, sumber dan pesan terfilter, sedangkan model 108 mengembalikan status `unavailable`. Ini tidak cukup untuk memverifikasi 23 sebagai quote final ataupun menyimpulkan penyebab `unavailable`. Uji ulang model 80 dengan filter status yang baru setelah deployment; jika tetap tersembunyi, status belum diketahui dan jangan menyetujui biaya berdasarkan angka saja.

Jika penyimpanan tidak tersedia atau belum dimigrasi, pengiriman gagal tertutup sebelum pemanggilan generasi. Jangan membagikan kunci service role. Migration perlu diterapkan sekali pada project yang benar sebelum deployment; jangan membuat atau mengubah tabel billing BLEA.\n\nMasukkan model dan prompt di bagian persiapan, lalu **Siapkan quote untuk persetujuan**. Server memeriksa model di katalog live, memanggil `get_model_help` dan `quote_generation` untuk model dan prompt persis tersebut; uji ini hanya mengirim parameter wajib, memakai default Freebeat dan tidak menebak opsi. Hanya respons `status=quoted` dengan `credits` numerik nonnegatif yang diterima untuk persiapan. Respons ini pernah terlihat untuk model 80, tetapi kontrak semantik dan biaya akhir masih perlu diverifikasi; teks sumber dan pesan penyedia tetap disembunyikan. Tidak ada opsi biaya tak diketahui.\n\nPersetujuan berisi prompt dan ID model yang ditampilkan serta batas `max_credits` tepat sebesar quote yang ditampilkan. Admin harus mencentang konfirmasi dan menekan tombol pengiriman satu kali. Bukti persetujuan terenkripsi sementara selama lima menit, terikat pada admin, token OAuth dan input; tidak disimpan di localStorage. Server meminta quote lagi dan menolak pengiriman bila angka atau status berubah. Token tidak dapat diubah untuk mengganti prompt, model atau batas. Ini mengirim `max_credits` tetapi tidak mengirim `accept_unknown_cost`; tidak menaikkan batas otomatis. Freebeat tetap menentukan biaya aktual, dan quote bukan tagihan maupun jaminan refund.\n\nSebelum panggilan yang mungkin berbayar, Worker memasukkan ID persetujuan unik ke tabel service-role-only. Indeks database melarang pengulangan receipt dan lebih dari satu pengiriman belum terselesaikan per admin. Timeout, respons tidak dikenal, atau kegagalan penyimpanan pascapengiriman dianggap **hasil tidak pasti**, mungkin sudah ditagih, dan tidak pernah dicoba ulang secara otomatis. Baris `dispatching` atau `unknown` mengunci pengiriman baru tanpa kedaluwarsa otomatis. Jika respons insert database sendiri hilang, Worker tidak memanggil Freebeat dan baris mungkin tetap terkunci. Jangan hapus baris karena ID yang sama dapat dipakai ulang.\n\nOperator harus merekonsiliasi hasil dengan aktivitas dan/atau dukungan Freebeat sebelum intervensi. Setelah yakin statusnya, operator dengan akses database yang berwenang dapat menandai baris `dispatching` atau `unknown` sebagai `reviewed`, membiarkan `task_id` null, untuk membuka kunci; ini tidak berarti refund dan tidak memicu ulang permintaan. Jika tugas ditemukan dan ID-nya tervalidasi, operator dapat menyimpan ID dan menetapkan `submitted`; jangan pernah menebak atau memindahkan tugas antar admin. Tidak tersedia tombol reset dari browser. Catatan hanya memuat admin, model, quote/batas, status, waktu, hash token sesi dan ID tugas, bukan prompt atau token.\n\n**Periksa catatan uji** menampilkan maksimum 20 catatan milik admin. Untuk `submitted`, **Periksa status** memanggil `get_task_status` menggunakan ID tugas yang disimpan, bukan ID arbitrer dari browser. Polling hanya tersedia selama sesi OAuth yang sama; setelah token kedaluwarsa atau berganti, periksa tugas di Freebeat secara manual. Link gambar HTTPS dari penyedia ditampilkan sebagai tautan eksternal, bukan di-fetch server; membukanya menghubungkan browser ke host penyedia. Nilai tagihan/refund yang tidak dilaporkan tetap null. Jangan bagikan ID tugas, URL bertanda tangan, prompt pribadi, token atau cookie.\n\nGenerasi ini dan bentuk `batch_id`/hasil status belum terverifikasi live; jika respons tidak cocok, anggap tidak pasti dan jangan ulangi. Uji ini tidak membangun akun provider bersama, riwayat gambar end-user atau sistem pengeluaran BLEA; pembelian BLEA tetap dinonaktifkan.

## Eksperimen saldo situs memakai cookie (terpisah dari MCP)

Bagian admin **Uji saldo situs dengan cookie** adalah diagnostik sekali pakai, bukan OAuth, MCP, integrasi akun bersama, atau sistem generasi. Gunakan hanya akun sendiri dan hanya jika ketentuan serta plan Freebeat mengizinkan akses ini. Freebeat mendokumentasikan OAuth untuk MCP, bukan penggunaan endpoint situs ini sebagai API publik. Hasil dan kompatibilitasnya tidak dijamin; kredit gratis tidak otomatis boleh dipakai secara komersial. Plan dengan manfaat manual-only dapat melarang akses otomatis/pihak ketiga.

Cookie sesi dapat memberikan akses luas ke akun Freebeat. Hanya setelah memahami risikonya, admin dapat menyalin **nilai header `Cookie` saja** dari permintaan `GET https://freebeat.ai/api/proxy/v1/user/credits/findCredits` di tab Network browser yang sudah login, lalu memasukkannya ke kolom bertipe password di halaman admin BLEA yang tepercaya. Jangan salin header lain atau `Copy as cURL`, dan jangan pernah kirim cookie ke chat, tiket atau pihak lain. Beberapa browser mungkin tidak menampilkan nilai header ini. Jangan menonaktifkan perlindungan browser untuk mendapatkannya.

Saat dikirim, cookie melewati browser, jaringan dan infrastruktur BLEA/Cloudflare, lalu diteruskan hanya dalam header `Cookie` ke endpoint HTTPS saldo tersebut. Admin harus mempercayai operator dan infrastruktur tersebut. Endpoint server memerlukan login bearer admin dan Origin BLEA yang sama, membatasi panjang input/respons, menolak pengalihan, dan tidak menampilkan isi respons mentah atau kesalahan dari penyedia. Hanya jumlah saldo numerik terpilih yang dikembalikan. Fitur ini tidak menyimpan cookie dalam database, localStorage, atau cookie BLEA, dan tidak sengaja mencatatnya; kolom dikosongkan saat submit. Cookie tetap dapat berada sementara di memori browser/Worker atau pada clipboard/peralatan browser, dan log/ekstensi/infrastruktur pihak ketiga di luar fitur perlu dipertimbangkan. Bersihkan clipboard setelah digunakan. Jika cookie bocor, akhiri sesi melalui Freebeat dan periksa keamanan akun.

Sesi mungkin kedaluwarsa atau memerlukan header tambahan; status HTTP 200 tidak cukup tanpa respons saldo yang valid. Permintaan ke MCP yang menggunakan cookie browser pada uji awal mengembalikan 401. Jika tes gagal, jangan mencoba melewati pembatasan penyedia; gunakan OAuth resmi atau tanyakan dukungan Freebeat. Uji tiruan: `node --test tests/freebeat-site-balance.test.js`. Belum ada jaminan pengujian live dari Worker berhasil.
