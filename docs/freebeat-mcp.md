# Freebeat MCP: uji koneksi admin

`/admin/freebeat` hanya tersedia untuk admin dan menawarkan OAuth, saldo, daftar model, inspeksi struktur tool, diagnostik quote dan uji generasi gambar admin dengan persetujuan untuk setiap pengiriman. Pembelian BLEA dan generasi untuk pengguna lain tidak diaktifkan. Backend memeriksa role admin pada setiap permintaan, menggunakan pendaftaran OAuth dinamis, PKCE S256 dan state yang terikat ke browser. Tombol Hubungkan Freebeat meminta `freebeat:read freebeat:generate` sekaligus; izin yang benar-benar diberikan tetap ditentukan Freebeat dan persetujuan admin. Endpoint resmi: `https://freebeat.ai/api/mcp`.

## Navigasi halaman percobaan

`/admin/freebeat` sekarang menjadi hub koneksi OAuth, pemeriksaan saldo, dan tombol akses percobaan, bukan tumpukan seluruh form. Semua URL di bawah tetap dilindungi `ProtectedRoute` dan `AdminRoute`; pemeriksaan admin backend tidak berubah.

| Kategori | Halaman percobaan (`/admin/freebeat/…`) |
| --- | --- |
| Gambar | `image-models` (katalog, help, skema), `image-edit` (probe edit + hosting foto), `image-generation`, `image-job` |
| Video | `video` (katalog + uji generasi), `hailuo` (uji satu video model 106), `ltx` (uji satu gambar/video model 97), `dance`, `singing`, `lip-sync` |
| Musik | `music` |
| Inspeksi MCP | `vocal-schemas`, `remaining-schemas`, `catalog`, `remaining-quotes` |

Setiap halaman memiliki judul, keterangan, status sesi dan tautan kembali. Singing dan Lip-Sync mempunyai form terpisah tanpa tombol berganti tool. Probe edit dan hosting foto tetap dalam satu halaman karena hosting memerlukan URL hasil probe.

Pindah halaman mereset form, respons privat dan persetujuan lokal; koneksi OAuth server/cookie tetap digunakan. Quote/persetujuan baru tetap wajib sebelum pengiriman berbayar. Catatan uji server tidak dihapus dan bisa dimuat kembali melalui tombol pemeriksaan catatan; jangan mengulang job yang hasilnya tidak pasti. Upload publik tidak otomatis dihapus saat pindah halaman: bersihkan lewat tombol halaman sebelum keluar, atau kelola objek tertinggal melalui Supabase Storage. Membuka hub tidak memuat katalog video; pemuatan katalog otomatis hanya berlaku pada halaman video/Hailuo. Membuka halaman tidak mengirim upload atau generasi berbayar. URL percobaan yang tidak dikenal menampilkan petunjuk kembali, bukan seluruh form.

Worker memerlukan `PROVIDER_CREDENTIAL_ENCRYPTION_KEY` yang sudah digunakan fitur Gmail. Jangan ganti kunci yang ada. Callback default: `https://blea-ai.blea-ai.workers.dev/api/freebeat/callback`. Opsional `FREEBEAT_OAUTH_REDIRECT_URI` dapat mengatur domain HTTPS lain dengan path yang sama; buka aplikasi dari origin tersebut agar cookie OAuth tersedia pada callback.

Token akses untuk pengujian dienkripsi AES-GCM ke cookie HttpOnly, Secure, SameSite=Lax, terikat ID admin, dan digunakan hanya setelah verifikasi admin. Tidak ada token refresh yang disimpan. Sesi berlaku paling lama satu jam (atau masa token yang lebih pendek); hubungkan ulang setelah kedaluwarsa. Setiap admin/browser punya sesi sendiri, belum ada akun provider bersama untuk pengguna. Tombol Putuskan menghapus cookie dan mencoba mencabut token; jika gagal, cabut akses di Freebeat. Perubahan kunci enkripsi juga mengakhiri sesi ini dan akan memengaruhi fitur Gmail yang memakai kunci yang sama.

Login OAuth, saldo MCP, daftar model dan quote gambar telah diuji live oleh admin. Pengiriman gambar dan format hasil belum diuji live. Tidak ada bypass pembatasan plan atau kredit. Penggunaan kredit Freebeat gratis bersifat nonkomersial menurut ketentuan Freebeat; akses untuk pengguna BLEA dan penggunaan komersial memerlukan pengecekan izin terpisah. Sistem kredit BLEA tidak terhubung ke Freebeat, dan pembelian tetap nonaktif.

Pendaftaran dinamis meminta response type `code`, grant `authorization_code` serta `refresh_token`, dan kedua scope baca dan generasi. Pendaftaran `freebeat:read` dengan callback default, login, dan pembacaan saldo MCP berhasil diuji live; setelah flow gambar, admin melihat tool `generate_image` dan memperoleh respons quote, tetapi pemanggilan generasi belum diuji live. Status izin gambar memperhitungkan scope pada respons token; jika respons menghilangkan `scope`, RFC 6749 menganggapnya sama dengan scope yang diminta, tetapi penggunaan aktual tetap belum terverifikasi. Sesi lama tanpa metadata scope diperlakukan sebagai baca saja. Jika Freebeat hanya memberikan scope baca, sesi tetap bisa membaca saldo dan menampilkan pemberitahuan izin terbatas. Grant refresh hanya metadata registrasi: BLEA tidak menyimpan atau menggunakan refresh token. Setiap percobaan koneksi BLEA membuat registrasi baru.

Unit/integration tests: `node --test tests/freebeat-mcp.test.js`; pengujian menggunakan respons upstream tiruan, bukan akun Freebeat asli. Eksperimen saldo situs melalui input cookie dan endpoint `site-balance` telah dihapus; tombol **Periksa saldo** resmi melalui MCP OAuth tetap tersedia.

## Diagnosis koneksi

Pada tahap registrasi atau pertukaran token, pesan menyertakan kode tetap yang aman untuk dibagikan: `FB-REGISTER-NETWORK`/`FB-TOKEN-NETWORK` berarti permintaan gagal sebelum menerima respons; `TIMEOUT` berarti batas waktu terlampaui; `HTTP` berarti Freebeat memberi respons penolakan; `RESPONSE` berarti respons JSON tidak valid; `REDIRECT` berarti pengalihan ditolak demi keamanan. Status HTTP registrasi dicantumkan jika tersedia. Detail mentah kesalahan, kode OAuth dan token tidak ditampilkan atau dicatat. Pengalihan 307/308 hanya diikuti sekali ke endpoint yang sama pada origin Freebeat yang sama, termasuk variasi garis miring akhir; semua pengalihan lain ditolak.

Jika registrasi (atau pertukaran token, status 400/401) mengembalikan kode kesalahan OAuth berbentuk pendek huruf kecil/garis bawah (format umum RFC 7591/6749, mis. `invalid_redirect_uri`, `invalid_client_metadata`, `unsupported_response_type`), halaman menampilkan kode tersebut apa adanya — tidak dibatasi daftar contoh tetap, karena kode itu sendiri bukan data sensitif. (Sebelumnya hanya kode yang sudah pernah terlihat pada uji langsung yang ditampilkan; kode baru dari Freebeat membuat pesan berhenti di "HTTP 400" tanpa penjelasan, sehingga koneksi ulang tidak bisa didiagnosis. Perbaikan ini tidak mengubah payload pendaftaran OAuth itu sendiri.) Jika penyedia menyebut loopback pada penolakan redirect, halaman menampilkan petunjuk tetap tanpa menyalin deskripsi mentah. Deskripsi mentah, isi respons penyedia lainnya, token, kode otorisasi, dan detail lain tidak ditampilkan atau dicatat. Respons kesalahan dibatasi 16 KiB.

Jika registrasi gagal dengan kode OAuth `server_error` (RFC 6749 §4.1.2.1: server otorisasi mengalami kondisi tak terduga di sisi Freebeat, bukan penolakan metadata klien kita), Worker mengeskalasi otomatis sampai berhasil atau tiga percobaan habis, lalu menampilkan kesalahan dari percobaan terakhir: (1) kombinasi lengkap (grant `authorization_code`+`refresh_token`, scope baca+generate); (2) payload identik sekali lagi setelah jeda singkat, untuk kemungkinan gangguan sesaat; (3) kombinasi yang sama tanpa grant `refresh_token` sebagai upaya terakhir, karena pada pengujian live kode `server_error` tetap muncul pada percobaan 1 dan 2 meski Freebeat diberi jeda, mengarah ke kombinasi grant tertentu dan bukan sekadar gangguan sesaat. Registrasi tidak punya efek samping sekali pakai (tiap percobaan selalu membuat klien baru), jadi aman diulang/dicoba dengan metadata berbeda. Kode OAuth lain (mis. `invalid_scope`, `invalid_redirect_uri`) tidak memicu eskalasi apa pun karena mengirim ulang atau mengubah grant tidak akan mengubah hasil untuk kasus tersebut.

Jika klien berhasil terdaftar tanpa grant `refresh_token` (percobaan ke-3), koneksi tetap berfungsi tetapi sesi tidak bisa diperpanjang otomatis mendekati kedaluwarsa token akses; percobaan `renewSession` berikutnya akan ditolak Freebeat dan pengguna perlu menghubungkan ulang secara manual lebih sering (bukan tiap bulan seperti normal). Ini regresi yang nyata namun jauh lebih baik daripada tidak bisa terhubung sama sekali. Jika ketiga percobaan tetap gagal dengan `server_error`, itu memastikan masalah ada di sisi Freebeat (bukan sesuatu yang bisa diperbaiki lewat metadata registrasi kita); hubungi dukungan Freebeat dengan kode ini atau coba lagi nanti.

Jika respons penolakan menyertakan header pelacakan permintaan yang dikenal aman (`cf-ray`, `x-request-id`, `request-id`, atau `x-amzn-requestid`, dengan bentuk token pendek tanpa spasi/karakter aneh), pesan dan log menambahkan `Ref: <id>` di akhir. ID pelacakan ini bukan data rahasia — justru sebaliknya, inilah yang dibutuhkan tim dukungan Freebeat untuk menemukan permintaan persis itu di log internal mereka saat melaporkan kegagalan yang terus terjadi (mis. `server_error` yang bertahan setelah ketiga percobaan registrasi di atas habis). Header yang tidak dikenali bentuknya (berisi spasi, tag, atau terlalu panjang) tidak pernah ditampilkan.

Semua permintaan OAuth ke Freebeat (registrasi, pertukaran/refresh token, pencabutan, pemanggilan MCP, dan penemuan metadata `.well-known/*`/`userinfo`) kini mengirim header `User-Agent` tetap (`UPSTREAM_MEDIA_USER_AGENT`, sama dengan yang dipakai proxy media Freebeat). `fetch()` Cloudflare Workers tidak mengirim User-Agent sama sekali secara default, dan CDN media Freebeat sebelumnya terbukti menolak permintaan tanpa User-Agent dengan HTTP 403. Pada uji live, ketiga percobaan eskalasi registrasi (payload lengkap, retry, tanpa grant `refresh_token`) gagal identik dengan `server_error` terlepas dari perbedaan `grant_types` — pola ini konsisten dengan sesuatu yang konstan di semua percobaan (seperti User-Agent yang kosong, mungkin diblokir/ditangani keliru oleh lapisan WAF/anti-bot di depan endpoint OAuth Freebeat) sebagai penyebab sebenarnya, bukan bentuk payload.

Untuk pemeriksaan saldo, kode `FB-MCP-INIT-*`, `FB-MCP-NOTIFY-*`, atau `FB-MCP-BALANCE-*` menunjukkan tahap yang gagal. Tahap `INSPECT` dan `MODELS` untuk persiapan gambar. Akhir kode `NETWORK`, `TIMEOUT`, `REDIRECT`, `HTTP`, `RPC`, `RESPONSE`, atau `SIZE` menunjukkan kategori aman; status HTTP disertakan jika relevan. Hanya tahap, kategori, dan status HTTP dicatat, bukan rincian provider atau kredensial. Pengalihan MCP selalu ditolak dan token tidak diteruskan ke tujuan lain. Respons saldo dibatasi 64 KiB dan respons discovery 256 KiB selama pembacaan; untuk SSE pembacaan berakhir saat respons dengan ID yang diharapkan diterima, tanpa menunggu stream ditutup.

## Persiapan gambar tanpa biaya

Tombol **Lihat model gambar** memanggil hanya `list_models` dengan `type=image`; tombol **Periksa skema tool gambar** memanggil `tools/list` (maksimal lima halaman) dan hanya menampilkan struktur terbatas untuk lima tool terkait gambar. Nilai contoh, deskripsi, URL, dan tool lain tidak diteruskan. Model dibatasi hingga 100 nama dan ID. Jika format model atau skema provider tidak cocok, tampilkan error aman, jangan menebak. Kedua langkah tetap admin-only, memakai sesi OAuth read-only yang sudah ada dan tidak memanggil `generate_image` atau `quote_generation`.

Form **Periksa respons quote** adalah diagnostik baca-saja. Hanya menerima ID model bilangan bulat dan prompt 1–2000 karakter, lalu memanggil `quote_generation` dengan `tool=generate_image` dan `parameters={model_id,prompt}`. Prompt dikirim ke Freebeat; jangan masukkan data rahasia. Respons disaring menjadi struktur dan nilai numerik/boolean serta daftar kecil nilai teks aman; teks lain, prompt dan identifier privat tidak diteruskan. Untuk field `status`, kosakata aman diperluas (misalnya `ok`, `quoted`, `priced`); nilai yang tidak ada dalam daftar tetap tersembunyi. Ini hanya diagnostik, bukan pernyataan bahwa semua nilai tersebut dipakai atau memiliki arti tertentu di Freebeat. Output ini belum diinterpretasikan sebagai biaya atau dijadikan persetujuan: bentuk respons nyata dan arti angkanya belum diverifikasi. Tidak ada `max_credits` atau `accept_unknown_cost` yang dikirim pada langkah ini.

Pada pengujian live dengan prompt yang sama, model 80 mengembalikan `credits: 23` tetapi status, sumber dan pesan terfilter, sedangkan model 108 mengembalikan status `unavailable`. Ini tidak cukup untuk memverifikasi 23 sebagai quote final ataupun menyimpulkan penyebab `unavailable`. Uji ulang model 80 dengan filter status yang baru setelah deployment; jika tetap tersembunyi, status belum diketahui dan jangan menyetujui biaya berdasarkan angka saja.

## Diagnostik upload gambar Freebeat

Pada bagian **Periksa pengambilan gambar oleh Freebeat**, admin dapat menyetujui pemeriksaan struktur `upload_image` dan quote untuk URL gambar yang sedang terisi. Pemeriksaan mengirim URL ke Freebeat tetapi tidak mengirim gambar melalui `upload_image` atau membuat video. Gunakan hanya gambar yang diizinkan untuk dibagikan; jangan gunakan URL bertanda tangan atau rahasia. Bila skema live tidak memiliki `urls` dan parameter numerik `max_credits`, atau quote untuk URL itu tidak berstatus `quoted` dengan kredit numerik tepat 0, upload diblokir. Error atau format tidak dikenal juga tidak mengaktifkan upload. `quote_generation` untuk `upload_image` serta dukungan limitnya **belum terverifikasi live**; tool mungkin tidak mendukungnya sehingga fitur ini mungkin tidak dapat melakukan upload.

Jika pemeriksaan lolos, admin masih harus secara terpisah menyetujui satu upload ke Freebeat. Worker memeriksa ulang skema dan quote lalu mengirim `upload_image` dengan satu URL dan `max_credits: 0`; tidak pernah mengirim `accept_unknown_cost` dan tidak membuat video. Batas dan quote bergantung pada Freebeat dan bukan jaminan tagihan aktual. Provider dapat menyimpan salinan gambar sesuai kebijakan dan masa retensinya; BLEA tidak menyediakan penghapusan salinan Freebeat. Hasil hanya mengungkap keberhasilan upload apabila Freebeat mengembalikan satu URL HTTPS yang valid, tanpa menyimpan atau menampilkan URL/isi respons. Ini tidak menjamin video dapat dihasilkan. Timeout, error setelah dispatch, respons tak dikenal, atau respons browser yang hilang dianggap tidak pasti; salinan mungkin sudah tersimpan. Jangan ulangi otomatis atau manual sebelum memeriksa Freebeat. Data hasil hilang saat URL diubah, sesi putus, atau halaman ditutup. Ini tidak menambahkan billing BLEA ataupun izin penggunaan bersama.

## Persiapan uji video tanpa biaya

Saat sesi terhubung, daftar dropdown dimuat dari `list_models(type=video)`; tombol **Muat ulang model video** memperbarui daftar. Hanya ID bilangan bulat yang dapat digunakan endpoint diagnostik dan ditampilkan; duplikat dan ID lain disaring. Daftar dibatasi 100 item dan dapat tidak lengkap; muncul di daftar bukan jaminan akses, dukungan opsi atau harga. Jika daftar gagal dimuat, kesalahan ditampilkan dan dapat dicoba lagi. **Periksa skema tool video** tetap menampilkan skema yang disaring. Keduanya tidak membuat video atau memakai kredit.

Pilih satu model di dropdown, pilih tipe input (`keyframe` untuk 0–2 gambar -> otomatis `text`/`image`/`transition`, atau `omni_reference` untuk 1–3 gambar -> `reference`), atur resolusi (`480p`/`720p`/`1080p` atau otomatis dari model), rasio aspek (`16:9`, `9:16`, `1:1`, dll.), dan durasi (bawaan 5 detik, hingga 30 detik untuk Wan 3.0 atau s/d 600 detik sesuai model), isi prompt dan hingga 3 URL HTTPS gambar (opsional untuk mode `keyframe` 0 gambar / text-to-video), lalu gunakan **Periksa informasi model** dan **Periksa quote**. Kedua tombol masing-masing memanggil `get_model_help` dan `quote_generation` untuk model dan parameter terpilih. Respons disaring dan mungkin tidak lengkap atau unavailable. Prompt dan URL dikirim ke Freebeat, tetapi tidak disertakan dalam hasil salin. Mengubah model, tipe input, resolusi, rasio aspek, durasi, prompt, daftar URL gambar, atau daftar model menghapus quote lama. Quote bukan biaya akhir atau persetujuan generasi.

Admin dapat membuka **Informasi model lebih lengkap (privat)**, membaca peringatan, mencentang persetujuan privasi dan menampilkan data `get_model_help` untuk model yang dipilih. Ini membaca model lagi tanpa quote atau generasi. Worker menghapus field sensitif dan menyamarkan pola URL, email dan kredensial sebisa mungkin, membatasi kedalaman, ukuran dan jumlah item; hasil mungkin terpotong dan penyamaran tidak dijamin lengkap. Jangan membagikan data mentah, token, URL, atau data pribadi. Output hanya tampil di browser, tidak disimpan atau dimasukkan tombol salin. Menutup lewat tombol sembunyikan, mengganti model, memuat ulang katalog atau memutus koneksi menghapus output dari tampilan. Ketiadaan opsi tetap bukan bukti bahwa fitur didukung atau tidak didukung.

Admin dapat membuka **Upload gambar ke Supabase (opsional, maks 3 gambar)** untuk mengunggah JPG/PNG/WebP maksimal 10 MB per gambar (maksimal 3 gambar per uji video) setelah menyetujui peringatan. Bucket `ai-studio-uploads` bersifat publik; gambar dan URL dapat ditemukan atau dibuka tanpa login. Jangan unggah data pribadi. File tidak kedaluwarsa otomatis; tombol hapus per gambar atau hapus semua tersedia selama halaman terbuka, kemudian hapus melalui dashboard Storage. Penghapusan tidak menghapus salinan atau cache pihak lain. Pengguna terautentikasi lainnya juga dapat mengunggah ke bucket bersama sesuai kebijakan yang ada.

Uji berbayar admin tersedia untuk model numerik yang dipilih dari katalog video terkini dan memiliki quote valid. Pilihan model, tipe input, jumlah gambar (0–3), resolusi, rasio aspek, dan durasi diikat ke persetujuan satu kali; dukungan opsi dan harga akhir tetap ditentukan Freebeat dan belum dijamin.

## Uji video berbayar khusus admin

Fitur memerlukan migrasi `20261118000005_create_freebeat_admin_video_tests.sql` dan service-role Worker. Pada project BLEA-AI `lwknqvgnxgecptkvtkfb`, migrasi ini sudah diterapkan sebagai versi `20261118152213`; jangan menerapkannya lagi hanya karena versi berbeda dari nama berkas. Tanpa tabel atau izin, pengiriman gagal sebelum pemanggilan berbayar. Uji hanya untuk akun OAuth admin, bukan pengguna lain atau kredit BLEA. ## Sesi tersimpan bukan pemeriksaan akses MCP

`GET /api/freebeat/status` membaca sesi lokal/server tanpa menghubungi Freebeat.
Label admin kini berbunyi **Sesi OAuth tersimpan**, bukan bukti koneksi sehat.
**Periksa saldo** menampilkan hasil pemeriksaan baca terakhir secara terpisah;
kegagalan menghapus hasil saldo lama. Pemeriksaan saldo berhasil bukan bukti
izin generasi, dan sesi tersimpan tidak otomatis dihapus saat gangguan jaringan.

Token hasil rotasi di database dapat memiliki waktu kedaluwarsa yang sama dengan
cookie lama. Jalur admin kini mengadopsi token database yang berbeda meskipun
`expiresAt` sama. Untuk pemeriksaan saldo dan quote vokal, penolakan HTTP 401/403
pada handshake `initialize` memicu satu pembacaan ulang sesi milik user/akun
yang sama. Jika ada token berbeda yang masih berlaku, handshake dicoba sekali
lagi menggunakan token itu. Jika akun cookie sudah hilang, jangan berpindah ke
akun legacy atau akun lain dalam pool.

Pemulihan ini tidak memaksa rotasi OAuth, tidak mengulang `tools/call`, dan tidak
mencoba ulang generasi berbayar. HTTP 402, 5xx, dan error jaringan tidak memicu
pemulihan handshake tersebut. Ini menangani kasus sesi usang yang dapat
reproduksi di tes, bukan membuktikan penyebab setiap penolakan Freebeat. Token
atau grant yang benar-benar dicabut tetap memerlukan otorisasi ulang; pemeriksaan
hak akses/plan tetap mengikuti Freebeat. Koordinasi refresh lintas Worker/isolate
tidak ditambahkan oleh perubahan ini.

### Quote upload ditolak meski sesi tersimpan

Status OAuth tersimpan tidak menjamin setiap tool/jenis quote didukung. `FB-MCP-QUOTE-RPC` pada tahap ini menunjukkan penolakan respons RPC/tool `quote_generation(tool=upload_image)`, bukan bukti upload foto ke Freebeat sudah terjadi. Foto sumber dapat sudah tersimpan di BLEA. Jangan simpulkan penolakan pasti karena token kedaluwarsa, akun/plan, atau quote upload tidak didukung hanya dari kode umum tersebut.

Endpoint `image-upload-quote` dan pemeriksaan ulang pada `image-upload-host` kini memakai `openMcpSession`: hanya handshake yang ditolak HTTP 401/403 boleh mencoba sekali salinan token terbaru milik akun/admin yang sama. Headers/token hasil handshake dipakai bersama untuk quote dan upload. Tidak ada tools/call yang diulang dan tidak ada pergantian ke akun pool lain.

Penolakan RPC quote dikembalikan sebagai `credits:null`, `status:quote_rejected`, serta diagnosis tetap/numerik (`stage`, `kind`, opsional `rpc_code`), tanpa pesan provider mentah, URL atau token. Ini membedakan sesi tersimpan dari penerimaan tool. Panel menampilkan **Diagnosis quote upload** yang dapat disalin; checkbox persetujuan numerik hanya muncul jika quote numerik valid, sedangkan checkbox unknown tetap terpisah dan tidak pernah dicentang otomatis. RPC `-32601`/`-32602`, penolakan tingkat tool (`result.isError:true`) meskipun tanpa kode RPC atau istilah enum/unsupported tertentu (tanpa indikasi penolakan akses/saldo/kegagalan sementara), atau status terstruktur `unavailable`/`unsupported` pada quote dapat menyediakan opsi **biaya TIDAK DIKETAHUI**; penolakan JSON-RPC umum lain, masalah transport/HTTP/akses, kegagalan sementara/internal, respons rusak, dan saldo habis tetap tidak membuka opsi tersebut. Kode parameter tidak valid sendiri tidak membuktikan semua instalasi MCP tidak mendukung quote upload.

Opsi berisiko ini mati secara default. Admin harus secara khusus mencentang satu upload tanpa harga/batas kredit keras dan tanpa jaminan refund. Request memakai `accept_unknown_cost:true` tanpa `expected_credits`; persetujuan numerik dan unknown tidak boleh digabung. Server memeriksa ulang kondisi: jika quote numerik kini tersedia atau kategori tidak lagi memenuhi syarat, upload ditolak dan diperlukan pemeriksaan/persetujuan baru. Quote numerik yang terlalu tinggi tidak boleh dialihkan ke jalur unknown. Persetujuan ini tidak memberi izin generasi atau quote video. Pemeriksaan quote ulang memakai sumber BLEA yang sudah ada, bukan mengunggah foto lagi.

Tombol **Hapus foto dari BLEA** menghapus sumber dengan verifikasi hasil Storage, bukan salinan Freebeat. Hapus sumber sebelum meninggalkan halaman; setelah navigasi, kelola objek tertinggal melalui Supabase Storage. URL Freebeat yang berhasil diperoleh tetap tersedia setelah sumber BLEA dihapus. Retensi salinan Freebeat mengikuti kebijakan penyedia.
