# Generate: gambar dan video multi-provider

Halaman `/generate` memisahkan pilihan **Generate gambar** dan **Generate video**. Integrasi setiap provider harus dibuat dan diverifikasi secara terpisah; label atau model di katalog tidak otomatis membuktikan kemampuan API provider.

## Gambar

Halaman Generate menampilkan daftar model dari `/api/image/config`: entri Freebeat 122 (jalur Freebeat consumer yang sudah ada) dan model gambar **Alibaba Model Studio** yang sudah diimplementasikan dengan adapter dan pengujian: `wan2.7-image`, `wan2.7-image-pro` (ukuran `1K`/`2K`, 1 gambar per permintaan), `qwen-image-3.0`, `qwen-image-3.0-pro` (preset ukuran `1664*928`, `1472*1104`, `1328*1328`, `1104*1472`, `928*1664`; 1–6 gambar; `prompt_extend` aktif), `qwen-image-2.0`, `qwen-image-2.0-2026-03-03`, `qwen-image-2.0-pro`, `qwen-image-2.0-pro-2026-03-03/-04-22/-06-22`, `qwen-image-2.1-pro`, `qwen-image-2.1-turbo` (ukuran bebas `LEBAR*TINGGI`, sisi 512–2048, default `2048*2048`; 1–6 gambar), dan `wan2.6-t2i` (ukuran bebas 1280–1440, default `1280*1280`; 1–4 gambar). Model yang muncul di daftar hanya jika semuanya terpenuhi: admin mengaktifkannya di Katalog Model (provider `alibaba`, aktif), menetapkan harga kredit aktif di Admin → Kredit (`modality` image), dan minimal satu akun Alibaba Cloud tersedia di pool/key admin. Bila harga belum diatur atau model belum diaktifkan, tombol generasi tidak aktif dan kredit tidak dipotong. Model gambar/video lain dari konsol free quota pengguna (wan2.1/2.2/2.5/2.6 t2i/i2v/r2v/vace/animate, happyhorse, z-image-turbo, wan2.6-image, wan2.2-t2i-*, qwen-mt-image-2.0, dst.) masih **katalog saja** — belum ada adapter + pengujian, sehingga tidak tampil dan ditolak bersih oleh API; jangan mengaktifkannya untuk pengguna.

Alur pengguna (async): periksa akun aktif → lookup harga `credit_model_prices` (`active=eq.true`) → debit `spend_credits` → submit ke `POST {base}/api/v1/services/aigc/image-generation/generation` dengan `X-DashScope-Async: enable` → simpan `external_job_id` di `image_generations` → polling `GET {base}/api/v1/tasks/{task_id}` lewat rute `/api/image/status`. Kegagalan definitif sebelum tugas terdaftar memicu refund otomatis; kegagalan jaringan/timeout TIDAK di-refund otomatis (status `unknown`, jangan ulangi). Refund otomatis juga terjadi bila provider melaporkan tugas FAILED. Parameter per model divalidasi di server; error upstream disanitasi (URL dan token panjang dibuang) sebelum diteruskan.

Sama seperti alur Freebeat: model dikunci/disiapkan server, kredit BLEA dipotong sisi server, riwayat per pengguna di `image_generations`. Penggunaan kredit akun Alibaba keluar dari akun admin yang terdaftar di pool (dengan failover dan cooldown), dan debit kredit BLEA pengguna tetap berlaku. Model Wan 3.0 video/chat tidak berubah; jangan mengaktifkan model gambar lain yang belum punya adapter + pengujian.

Status verifikasi: adapter dan pengujian unit/integrasi lulus, tetapi belum diuji live end-to-end dengan akun Alibaba sungguhan maupun kredit BLEA sungguhan; klaim "siap produksi" menunggu uji live yang digerakkan admin.

Untuk pengujian admin Freebeat (OAuth dengan izin gambar di `/admin/freebeat`), alurnya tetap seperti sebelumnya: quote, persetujuan per pengiriman dengan `max_credits`, receipt terikat sesi, dan penguncian hasil tidak pasti seperti dijelaskan di `freebeat-mcp.md`. Uji ini memakai kredit akun Freebeat admin dan bukan pembelian atau pemotongan kredit BLEA.

## Video

Halaman menampilkan hanya model video yang ditandai aktif di Admin Panel dan memiliki provider dengan kredensial serta base URL yang dapat digunakan. Jika belum ada, daftar kosong dan tombol generate dinonaktifkan; tidak memakai fallback model atau provider. Provider lain dapat memakai jalur video yang sudah ada sesuai protokol provider yang didukung. Input media untuk jalur lama diunggah ke bucket publik sehingga dapat diakses melalui URL; tampilkan dan pahami peringatan sebelum mengunggah. Periksa kompatibilitas masing-masing provider sebelum produksi.

UnoRouter tidak lagi ditampilkan di katalog video dan `/api/video/models` tidak meminta katalog UnoRouter. `/api/video/generate` menolak provider tersebut atau provider kosong; ini tidak menghapus kredensial atau pengaturan UnoRouter dari fitur Chat/Admin, dan tidak menghapus riwayat video lama. Riwayat lama tetap dapat dipantau/diakses melalui mekanisme sebelumnya. Provider tanpa base URL valid tidak boleh jatuh diam-diam ke URL provider lain.

**Batasan penting:** jalur video lama belum menegakkan saldo/debit kredit BLEA, idempotensi tagihan, atau quote Freebeat. Pemanggilan melalui provider lama dapat memakai saldo provider; angka harga historis pada katalog bukan konfirmasi biaya. Pembelian kredit BLEA tetap nonaktif. Freebeat image-to-video belum dihubungkan ke `/generate`; bagian admin menyediakan uji Wan 3.0 terpisah dengan quote, persetujuan per pengiriman dan penanganan hasil tidak pasti; hal ini bukan generasi untuk pengguna biasa dan belum diuji live. Penggunaan untuk pengguna lain juga memerlukan izin Freebeat sesuai ketentuan penyedia.
